# 공덕경희 대사건강 리포트

검사수치를 입력하면 5개 축, 총 100점 기준의 대사건강 리포트를 생성하는 정적 웹앱입니다.

## 주요 기능

- 환자 기본정보 입력
- 5개 축 자동 점수 계산
- 오각형 레이더 차트
- 총점 및 관리등급 표시
- 치료 우선순위 1, 2순위 표시
- 경고 플래그 및 해석 주의 표시
- 옴니핏 HRV-Index 및 Stress 판정 기반 자율신경(스트레스) 점수
- 브라우저 인쇄를 통한 PDF 출력

## 로컬 실행

정적 파일 서버로 프로젝트 폴더를 열면 됩니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`으로 접속하세요.

## 기준

`공덕경희 대사건강 평가기준 v4.2`를 기반으로 합니다.
질병 확진 목적이 아닌 프로그램 운영용 관리 지표이며, 총점보다 개별 경고 플래그와 임상 판단을 우선합니다.
